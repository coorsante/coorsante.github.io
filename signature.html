Nouvel Outlook (Windows) / Outlook sur le web

  1. Cliquez sur la roue dentée Paramètres → Comptes → Signatures.
  2. Cliquez sur + Nouvelle signature, nommez-la « Coorsanté ».
  3. Dans la zone de texte, faites Ctrl+V pour coller.
  4. En dessous, choisissez « Coorsanté » pour les nouveaux messages et les réponses/transferts, puis Enregistrer.

Outlook classique (Microsoft 365, 2016–2021)

  1. Fichier → Options → Courrier → bouton Signatures…
  2. Nouveau, nommez-la « Coorsanté », puis collez (Ctrl+V) dans la zone d'édition.
  3. À droite, choisissez le compte contact@coorsante.fr et sélectionnez « Coorsanté » pour les nouveaux messages et les réponses. OK.
À savoir : l'animation du logo s'affiche dans la plupart des messageries (Gmail, Apple Mail, nouvel Outlook, Outlook mobile). L'Outlook classique sur Windows n'affiche que la première image d'un GIF animé : vos destinataires y verront le logo complet, immobile. Si le logo n'apparaît pas chez un destinataire, c'est que sa messagerie bloque les images distantes : il lui suffit de cliquer sur « Afficher les images ».
